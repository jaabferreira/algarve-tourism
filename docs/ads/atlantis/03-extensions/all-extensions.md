# Shared Extensions — Atlantis (account-level)

These extensions ("assets" in the Google Ads UI since 2023) are applied at the **account level** and inherited by all 6 campaigns: Brand, Benagil, Algarve Generic, Cranchi, Sail, Reef Fishing.

Setting them once at account level — instead of duplicating per-campaign — means edits propagate everywhere.

## How to load these in Google Ads

1. **Tools & Settings → Ads & Assets → Assets**
2. Click **+ Asset** → pick the type → fill the fields below.
3. Each asset can be scoped to: account-wide, specific campaigns, or specific ad groups. Default to **account-wide** for all of these.
4. For language-specific text (callouts, sitelinks): create separate assets per language and use the **language targeting** setting on each — Google will only serve the matching one based on the campaign/ad group's language.

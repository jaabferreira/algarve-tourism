# Atlantis ES/FR Tour-Localization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `/es/` and `/fr/` Atlantis tour pages, homepage, and booking flow render fully in the target language (no English fallback), rebuilt and live.

**Architecture:** Open the two English-fallback gates — the fetch gate (`scripts/fetch-fh.ts` bakes only pt/en) and the render gate (`packages/atlantis/src/data.ts` maps only en/pt) — then re-fetch FareHarbor's existing es/fr product content and 301-redirect the old English-slug ES/FR tour URLs to their new native slugs. Deploy is a push to `master`; Cloudflare Pages re-runs the FH fetch in its build.

**Tech Stack:** Astro 5, pnpm workspaces + Turborepo, TypeScript, FareHarbor External API v1, Cloudflare Pages (`_redirects`).

## Global Constraints

- Scope is `packages/atlantis` only. Do **not** touch `packages/algarve-and-you/src/data.ts` (its es/fr data will be baked by the fetch change but must stay on English fallback — no live ads there).
- Baked data (`packages/shared/data/*.json`) is **gitignored** — never `git add` it; it is regenerated by CF at build.
- FareHarbor product names can change; slug redirect pairs must be read from the freshly-baked JSON, not hand-copied.
- Redirect format is Cloudflare `_redirects`: `<from> <to> 301`, one per line; append, don't reorder existing rules.
- Commit-message trailer: end every commit with `Co-Authored-By: Claude Opus 4.8 (1M context) <noreply@anthropic.com>`.
- Log the change in `GoogleAds/atlantis/06-changelog.md` (landing-page change affecting live ads — per the project Google Ads logging rule).
- No push until local verification passes (build + rendered-output inspection).

## File Structure

- `scripts/fetch-fh.ts` — add es/fr to `FH_LANGUAGES` (fetch gate).
- `packages/atlantis/src/data.ts` — add es/fr to `FH_LOCALE_MAP` (render gate).
- `packages/atlantis/public/_redirects` — append 8 back-redirects for old ES/FR tour slugs.
- `packages/shared/src/lib/fareharbor.ts` / `packages/shared/src/components/BookingWidget.astro` — only if the FH embed supports a language param (Task 4).
- `GoogleAds/atlantis/06-changelog.md` — changelog entry.

Note on testing: this is a build-time data-baking change, so the meaningful test is **built-output inspection** (do `/es/` and `/fr/` pages contain translated strings and native slugs; do old URLs 301), not a classic unit test. Verification steps below are the test cycle.
